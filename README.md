# AI创新实践

面向中学生社团课的本地课程网站，围绕“认识 AI、学会表达、完成作品、连接竞赛”展开。

## 课程特色

- 15 节课、每节约 40 分钟
- 三组“两课时短挑战”
- 学生自主选择海报、视频、网站、智能体等作品形式
- 教师讲解必要原理与提示词方法，课堂以讨论、协作和创作为主
- 提供人工智能竞赛方向参考与项目推进工具
- 不要求学生使用手机或注册个人账号
- 学习记录保存在浏览器本地，并支持导入、导出

## 本地运行

macOS 可双击 `启动AI创新实践.command`，Windows 可双击 `启动AI创新实践.cmd`。

也可以在项目目录运行：

```bash
npm start
```

然后访问 <http://localhost:4185/>。

## 检查与构建

```bash
npm run check
npm run build
```

详细说明见 [使用说明.md](./使用说明.md)，课程文本汇总见 [课程内容全集.md](./课程内容全集.md)。

## 使用说明

网站当前不连接付费 AI 接口，不会自行产生 API 费用。教师可在学校允许的统一环境中展示或接入 AI 工具，学生使用小组共创和轮换体验的方式参与。
